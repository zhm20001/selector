Selector fixture — Shadow DOM

手动验收用示例页：先在安装页拖走 Selector 书签，再回到本页点击书签激活选择。 每个区块对应 issue #1 的一条验收标准，块下方的 ☐ 列表就是操作步骤。 closed 区块的行为必须保持“选中 host”，不允许穿透。

1. Open shadow root：悬停与点击命中内部元素

☐ hover 卡片标题 → 覆盖框贴住标题文本（不是整卡）
☐ hover 中间的「确认」按钮 → 覆盖框贴住按钮；点击选中，⌘C 复制的 prompt 描述 button 而非 host
☐ hover 底部纯文本 span → 能选到该 span
☐ Shift+点击加选第二个元素 → 两框并存；⌘Z 撤销 / Esc 清除行为正常

2. 嵌套 open shadow root：连续跨两层边界

☐ hover 内层徽标 → 覆盖框贴住徽标（外层组件影子树里的内层组件影子树）
☐ hover 内层灰字 → 不可见/无意义爬升启发式仍然生效，选中最近的有意义祖先

3. Open shadow 内的 disabled 控件（elementsFromPoint 兜底）

☐ hover 灰色「已禁用」按钮 → 选中该 disabled button 本身，而非其影子祖先
☐ 点击选中后 ⌘C → prompt 中 tag 为 button、可见文本为「已禁用」

4. Open shadow 内的表单输入

☐ hover 输入框 → 选中 input（含 placeholder 语义）；点击选中不弹页面自身的提交行为
☐ 在输入框内打字时不被 Selector 的快捷键吞掉正常字符以外的行为保持与主树一致

5. Closed shadow root：行为必须与现状一致

☐ hover 卡片内任意位置 → 选中并只显示外层 <closed-card> host 的覆盖框
☐ ⌘C → prompt 描述 host（tag closed-card），不出现影子树内部元素
☐ 控制台不应出现任何访问 closed root 的报错

6. 主树基线（回归对照）
